# pump_prep — запуск

Prep-сигналы + граф-сканер. Обычно стартует из корня MUTE.

```bash
cd ./MUTE
./scripts/start_prep.sh
./scripts/start_scanner.sh
```

Или:

```bash
cd ./MUTE
PYTHONPATH=. python -m pump_prep run
PYTHONPATH=. python -m pump_prep panel
```

Отчёты: `pump_prep/out/*.html`. Корень панели MUTE: http://127.0.0.1:8765/
