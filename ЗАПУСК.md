# MUTE — запуск

Мониторинг кошельков (DWF / prep) → Telegram + HTML-панель управления.

## Требования

- Python 3.10+
- Файл `.env` с `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `ETHERSCAN_API_KEY`

## Один раз: подготовка

```bash
cd ./MUTE
cp -n .env.example .env
# заполнить ключи в .env
chmod +x START.sh scripts/*.sh
./START.sh
```

`START.sh` создаёт `.venv`, ставит зависимости, проверяет Telegram и поднимает монитор + dashboard.

## Рекомендуемый рабочий сценарий

```bash
./scripts/start_dashboard.sh   # панель http://127.0.0.1:8765/
# в панели: «Старт системы» / сканы / отчёты
```

| URL | Что |
|-----|-----|
| http://127.0.0.1:8765/ | Control panel |
| http://127.0.0.1:8765/launch.html | Launch hub |

## По частям

| Что | Команда |
|-----|---------|
| DWF monitor | `./scripts/start.sh` |
| Prep → Telegram | `./scripts/start_prep.sh` |
| Graph scanner | `./scripts/start_scanner.sh` |
| Розвідка (DeepSeek) | `./scripts/start_rozvidka.sh` → http://127.0.0.1:8765/rozvidka.html |
| Статус | `./scripts/status.sh` |
| Стоп DWF | `./scripts/stop.sh` |
| Стоп всё | `./scripts/stop.sh --all` |
| Стоп dashboard | `./scripts/stop_dashboard.sh` |
| Стоп scanner | `./scripts/stop_scanner.sh` |

## Подпроекты

| Папка | Запуск |
|-------|--------|
| `mute/` | через `./scripts/start.sh` (см. также `mute/ЗАПУСК.txt`) |
| `pump_prep/` | `./scripts/start_prep.sh` · `./scripts/start_scanner.sh` |
| `crypto_funds_tracker/` | `cd crypto_funds_tracker && .venv/bin/python main.py` → `out/crypto_funds_report.html` |

Логи/PID: `logs/*.out`, `*.pid`. Панель открывать как **http://**, не `file://`.
