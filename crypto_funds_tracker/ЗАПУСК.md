# Crypto Funds Tracker — запуск

Отчёт по DAT/mid-cap фондам → HTML.

```bash
cd ./MUTE/crypto_funds_tracker
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python demo.py     # без ключей
python main.py     # живые данные
```

Отчёт: `out/crypto_funds_report.html` (также в панели MUTE → Reports).
